    Pipeline

    How SignalScope works

    01

    Upload image

    Choose or drag a file. The image is validated for type and size, then shown as a preview before anything runs.

    02

    Image analysis

    The frame is decoded and normalized so the classifier sees a consistent input regardless of camera or source.

    03

    AI detection

    A convolutional backbone scores the image as AI-generated or real. The frontend stays model-agnostic.

    04

    Confidence

    The raw score is reported as a confidence value between 0 and 1, shown as a likelihood rather than a certainty.

    05

    Visual explanation

    A Grad-CAM style heatmap highlights the regions the network relied on, so the verdict can be inspected.

    06

    Final result

    Verdict, confidence, heatmap and written signals are presented together, and you can immediately run another image.

    Reading the output

    What the score means

    • A verdict says likely AI-generated or likely real — it is never a statement of fact.
    • Confidence describes how strongly the model leaned one way, not the chance an image is genuine.
    • The heatmap shows which regions the network reacted to; it does not prove an image was synthesized.
    • Cropped, compressed or heavily edited images are harder to judge and can score unreliably.
    Limits & fairness

    Use it carefully

    • Detectors improve alongside generators — today's accuracy is not guaranteed tomorrow.
    • False accusations damage people. Never publish or act on a verdict alone.
    • Results can vary by content type, skin tone and lighting; treat edge cases with extra caution.
    • This build runs entirely in the browser with mock results — no image is uploaded or stored.
